# projectmanagement

A proof-of-concept, Jira-style project management tool: issues, a kanban board, and swimlanes (by assignee, epic or priority), built because Jira is too expensive for a personal project.

Status: setup. The first spec, the board MVP, is in progress in `docs/specs/`.

See `CLAUDE.md` for how the AI dev team (product manager, developer, QA) builds this.
