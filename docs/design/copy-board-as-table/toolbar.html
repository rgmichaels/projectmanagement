Copy board: toolbar states

Each frame is the Board toolbar (project title, badge, Group by, Copy board, Create work item, filter bar). The button reuses the Daily Report "Copy for email" style (button.navy) and its confirmation line (.copy-status). Forced hover and focus classes are mockup-only; real ones are :hover and :focus-visible.

1. Default (active sprint, signed in with write rights)

Copy board sits immediately after Group by and before Create work item. Group by keeps its right-aligning auto margin, so the cluster Group by, Copy board, Create work item stays together at the right.

2. Hover and keyboard focus

Hover: fill changes from navy to teal (same pair the app already uses). Focus: the app-wide 2px teal ring with 2px offset; no custom ring. Tab order: Group by, Copy board, Create work item.

EFS Automation

3. Copied (about 4 seconds, then cleared; focus stays on the button)

The line is a p.copy-status.ok[role="status"] to the right of the button: a check mark, teal bold text "Copied. Paste into your email." Same text, colour and clearing time as the Report page. It is in the live region before it is filled, so screen readers announce it.

4. Error (clipboard API and the selection fallback both failed)

Danger bold text "Could not copy. Select the board and copy it by hand." as p.copy-status.fail[role="alert"]. It stays until the next copy attempt or until the filters, grouping or sprint change. Focus returns to the button. The button is never disabled.

5. Fallback in progress (clipboard API missing or rejected)

Invisible to the user: the code builds the same table off-screen (position:absolute; left:-9999px; aria-hidden="true"), selects it, calls execCommand('copy'), removes the selection and the node, and shows the normal Copied line (state 3) on success or the error (state 4). No extra UI. The live board never changes.

6. Viewer or archived project (read-only): button still shown

Copy is a read action. Create work item is hidden, Copy board is not disabled. Archived keeps the existing "Archived (read-only)" badge.

7. No active sprint: button hidden

The board is not drawn, so Group by, the filter bar and Copy board are all hidden (hidden attribute on the .copy-board wrapper, set in the same place as els.groupBy.closest('label').hidden = !active). Any old status text is cleared when hidden.

The wrapper drops to its own full-width line; the confirmation text wraps under the button. No horizontal scroll.

9. Hostile or long text
